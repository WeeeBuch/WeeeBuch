# IT Company Website

## Overview
This project is a modern minimalist website for an IT company. It showcases the company's services, provides information about the company, and includes a contact section for potential clients.

## Project Structure
```
it-company-website
├── src
│   ├── index.html        # Main HTML document for the website
│   ├── css
│   │   └── style.css     # Styles for the website
│   ├── js
│   │   └── main.js       # JavaScript for interactivity
│   └── assets
│       └── fonts         # Font files for consistent typography
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd it-company-website
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open `src/index.html` in your browser to view the website.

## Features
- Modern minimalist design
- Responsive layout for various devices
- Interactive elements powered by JavaScript

## Usage Guidelines
- Modify the content in `src/index.html` to update the website's information.
- Customize styles in `src/css/style.css` to change the appearance of the website.
- Add any additional JavaScript functionality in `src/js/main.js`.
